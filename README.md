# 🌱 Shree Ganesh Fertilizers and Pesticides

A responsive agricultural products e-commerce website developed for **Shree Ganesh Fertilizers and Pesticides**.

The website allows customers to explore fertilizers, seeds, and agricultural products, add products to their cart, register/login, and place orders. The project also uses PHP and MySQL for handling user and order data.

---

## 📌 Project Overview

**Shree Ganesh Fertilizers and Pesticides** is a web-based shopping platform designed to make it easier for farmers and customers to browse and purchase agricultural products online.

The project provides a simple and user-friendly interface for:

- 🌾 Fertilizer products
- 🌱 Seeds
- 🛒 Shopping cart
- 👤 User registration and login
- 📦 Online order placement
- 💳 Payment method selection
- 📱 Responsive interface
- 💾 MySQL database integration
